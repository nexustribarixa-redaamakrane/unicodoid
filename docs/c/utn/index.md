# C — UTN (Unicode Technical Notes)

This directory holds the C SDK's documentation disposition of Unicode
Technical Notes. UTNs are not standards and introduce no generated data tables.

| Doc | Note | Disposition |
| --- | --- | --- |
| [utn1.md](utn1.md) | UTN #1, "Issues in Indic Language Collation" | Documentation only; catalogued, no runtime behaviour derived from it |

**No `src/` module** corresponds to this note, by design. Collation
conformance rests on [UTS #10](../uts/uts10.md) and the generated UCA data.

Shared disposition: `docs/unicode18/utn/utn1.md`.
