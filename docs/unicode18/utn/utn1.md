# Unicode Technical Note 1 — Issues in Indic Language Collation (documentation disposition)

- **Unicode Technical Note:** UTN #1, "Issues in Indic Language Collation"
- **Reference:** https://www.unicode.org/notes/tn1/
- **Status:** Technical Note (documentation only; not a UAX/UTS/UTR/TR)

## Disposition

UTN #1 is an independent author work and is not part of the Unicode standards
process. Unicodoid lists it in the specification catalog with category `UTN`,
number `1`, and treats it as documentation only:

- No runtime behaviour is asserted from the note.
- No SDK algorithm is derived from or tuned to the note.
- Conformance claims for collation rest on UTS #10 and the generated UCA data.
